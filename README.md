# Superstore Profitability Analysis

## Project Overview
This project analyzes Superstore sales data to identify profit trends, discount impact, category performance, and regional profitability using Python.

## Business Problem
The objective is to understand which product categories and regions generate the highest profits and how discounts affect overall business profitability.

## Dataset
- File: Superstore_clean_Data.csv
- Records: 9,994
- Columns: 21
- Period: 2014–2017

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
- Looker Studio
- GitHub

## Key Results
- Total Sales: $2,297,200.86
- Total Profit: $286,397.02
- Overall Profit Margin: 12.47%
- Most Profitable Category: Technology
- Lowest Regional Profit Margin: Central (7.92%)

## Key Findings
- Technology generated the highest category profit.
- High discounts were associated with significant losses.
- Tables and Bookcases were loss-making sub-categories.
- The Central region had the lowest profit margin.

## Business Recommendations
- Review discount policies, especially discounts above 20%.
- Reassess pricing and profitability for Tables and Bookcases.
- Investigate the reasons for lower profitability in the Central region.
- Focus on profitable products and categories.
